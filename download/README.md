# Download Operation Value Chain (Windows)

1. Download all seven files: `OperationValueChain-win64.7z.001` to `.007`. Open each one on GitHub and click **Download raw file**.
2. Put them in one folder.
3. Right-click `OperationValueChain-win64.7z.001` and extract it with [7-Zip](https://www.7-zip.org/) (or WinRAR). It joins the parts automatically.
4. Run `OperationValueChain\OperationValueChain.exe`.

It's a native Windows game (Godot 4.5) with no installer. It needs a Vulkan-capable graphics card. If it won't start, make a shortcut and add `--rendering-driver d3d12` to the end of the Target field.
